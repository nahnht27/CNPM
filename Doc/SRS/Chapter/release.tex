\subsection{Hướng dẫn cài đặt}

\subsubsection{Backend}

\textbf{Step 1:} Download \& Install Visual Studio Code:
\href{https://code.visualstudio.com/download}{Visual Studio Code}.

\vspace{0.3cm}

\textbf{Step 2:} Download \& Install Git:
\href{https://git-scm.com/downloads}{Git}.

\vspace{0.3cm}

\textbf{Step 3:} Download \& Install Python:
\href{https://www.python.org/downloads/}{Python}.

\vspace{0.3cm}

\textbf{Step 4:} Download \& Install PostgreSQL:
\href{https://www.postgresql.org/download/windows/}{PostgreSQL}.

\vspace{0.3cm}

\textbf{Step 5:} Clone source code:
\href{https://github.com/nahnht27/CNPM}{GitHub}.

\vspace{0.3cm}

\textbf{Step 6:} Cài đặt các thư viện cần thiết cho Backend.

\vspace{0.3cm}

\textbf{Step 7:} Cấu hình thông tin kết nối PostgreSQL trong file
\texttt{.env} để kết nối Backend với cơ sở dữ liệu trên Supabase.

\vspace{0.3cm}

\textbf{Step 8:} Tạo môi trường ảo Python:
\verb|python -m venv .venv|

\vspace{0.3cm}

\textbf{Step 9:} Kích hoạt môi trường ảo:
\verb|.venv\Scripts\Activate.ps1|

\vspace{0.3cm}

\textbf{Step 10:} Cài đặt các thư viện cần thiết:
\verb|pip install -r requirements.txt|

\vspace{0.3cm}

\textbf{Step 11:} Di chuyển đến thư mục Backend của project:
\verb|cd D:\CNPM\Flask-cleanArchitecture\src|

\vspace{0.3cm}

\textbf{Step 12:} Khởi động Backend:
\verb|python app.py|

\vspace{0.3cm}

\textbf{Step 13:} Sau khi Backend khởi động thành công, hệ thống được truy cập thông qua địa chỉ:
\verb|http://127.0.0.1:9999|

\subsubsection{Frontend}

\textbf{Step 1:} Mở thư mục Frontend của project bằng Visual Studio Code.

\vspace{0.3cm}

\textbf{Step 2:} Kiểm tra cấu hình địa chỉ Backend trong mã nguồn Frontend:
\verb|http://127.0.0.1:9999|

\vspace{0.3cm}

\textbf{Step 3:} Cài đặt extension \textit{Live Server} trên Visual Studio Code.

\vspace{0.3cm}

\textbf{Step 4:} Mở file \texttt{index.html} hoặc trang cần chạy trong thư mục Frontend.

\vspace{0.3cm}

\textbf{Step 5:} Nhấn chuột phải vào file HTML và chọn
\textit{Open with Live Server}.

\vspace{0.3cm}

\textbf{Step 6:} Trình duyệt web sẽ tự động mở địa chỉ Frontend. Người dùng có thể truy cập hệ thống thông qua địa chỉ được cung cấp bởi Live Server.

\vspace{0.3cm}

\textbf{Step 7:} Đảm bảo Backend đang được chạy tại địa chỉ
\verb|http://127.0.0.1:9999|
để Frontend có thể gửi request và nhận dữ liệu từ hệ thống.
